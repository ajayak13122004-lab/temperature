🌡️ Temperature Converter

A simple and user-friendly web application to convert temperatures between Celsius, Fahrenheit, and Kelvin using HTML, CSS, and JavaScript.

---

🚀 Features

- Convert between:
  - Celsius → Fahrenheit / Kelvin
  - Fahrenheit → Celsius / Kelvin
  - Kelvin → Celsius / Fahrenheit
- Clean and modern UI
- Instant result display
- Input validation (handles invalid inputs)

---

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

📂 Project Structure

temperature-converter/
│── index.html
│── style.css
│── script.js

---

▶️ How to Run

1. Download or clone this repository
2. Open the project folder
3. Double click index.html
4. Start converting temperatures 🎉

💡 Example

Input: 100°C
Output: 212°F
